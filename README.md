Descripción del ejercicio

Esta es la solución de un taller realizado en python. El programa simula el cálculo de pagos para tres tipos de empleados de una empresa: empleados de tiempo completo, empleados por horas y empleados por comisión. Para cada uno, el programa calcula el salario bruto, las deducciones de ley del 4% para salud y 4% para pensión, el auxilio de transporte cuando aplica, y el pago neto. Al final muestra un reporte con los totales pagados por cada tipo.
